# Component Library

## M1

The account-entry UI currently uses the React/Vite artifact scaffold and its accessible form primitives. The register, login, and signed-in landing screens provide the first interaction patterns. The complete reusable component library, theming, command palette, responsive universe navigation, and cross-module states are M2 deliverables.

## Conventions

- Use semantic controls and visible keyboard focus.
- Keep loading, validation, error, empty, and success states explicit.
- Avoid decorative controls that do not act.
- Do not use color alone to convey state.
- The normative visual tokens and accessibility direction are in `docs/specifications/WORLDWEAVE_M0/DESIGN_SYSTEM.md`.
